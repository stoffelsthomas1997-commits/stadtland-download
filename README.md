# Civic Hijack für Windows

Die Downloadseite: https://stoffelsthomas1997-commits.github.io/stadtland-download/

Installer: https://github.com/stoffelsthomas1997-commits/stadtland-download/releases/latest/download/CivicHijack-Installer.exe

Der kleine Windows-Installer lädt die aktuelle Version, installiert den Launcher und legt eine Desktop-Verknüpfung an. Der Launcher prüft beim Start auf Updates und verwendet nach Möglichkeit Differenzpakete. Spielstände und Benutzerprofile bleiben getrennt von der Installation.

Dieses Downloadprojekt enthält die Website und verteilbare Spielpakete. Spielcode, private Schlüssel, Zugangsdaten und persönliche Spielstände werden hier nicht veröffentlicht.

Seit Version 0.87 heißt STADTLAND Civic Hijack. Bestehende Launcher und Spielstände bleiben kompatibel. Die früheren Updateadressen werden weiter bedient.
